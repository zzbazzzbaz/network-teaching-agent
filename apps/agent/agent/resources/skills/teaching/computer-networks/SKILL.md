# 计算机网络教材

> 状态：占位。教材正文尚未接入，`textbook/` 下目前只有索引占位。学生询问具体教材内容时，明确说明尚未接入，不要编造章节、页码、题号或原文。

## 1. 何时使用

使用：

- 学生要预习、复习或定位计算机网络某一章；
- 学生问分层、协议、算法、设备等课程概念；
- 习题需要确认知识点属于哪一章；
- 考研复习需要把考点映射到教材章节；
- 需要引用教材中的定义、图或例题时。

不要使用：

- 实验步骤、traceroute 代码和沙箱操作，走 `traceroute-lab`；
- 题库检索；当前没有题库工具；
- 需要教材原文但尚未接入的内容。

## 4. 阅读策略

1. 先读 `textbook/00-index.md`，确认章节和文件；
2. 再读当前问题对应的章节，不要一次读完整本教材；
3. 需要定位关键词时用 `grep`，再用 `read_file` 读取具体段落；
4. 只引用回答所需的 1–2 段，不整章粘贴；
5. 教材没有写的内容，明确说“当前资料没有覆盖”，不要补写；
6. 不伪造页码、版本、作者、题号或原文。

## 5. 与三种教学模式结合

### 预习

- 用教材目录和章节导语建立框架；
- 标出前置概念和 2–3 个预习问题；
- 不直接把整章内容讲完。

### 习题

- 先用教材定位知识点和定义；
- 给提示而不是直接给答案；
- 学生答完后，用 `ask_student` 检查是否理解关键条件。

### 考研

- 用教材章节映射考纲和题型；
- 讲考点结构、评分点和常见边界；
- 不承诺押题，不编造真题年份或来源。

## 6. 与其他 skill 的关系

- `ask-student`：负责设计检查题；出题前按需读教材章节；
- `memory-maintenance`：负责记录教学进度、概念掌握和误解；
- `traceroute-lab`：实验专用，不用于教材概念讲解。

## 7. 边界

- 当前没有教材正文；不要假装已经读过；
- 不把教材全文一次性加载；
- 不引用未提供的外部资料；
- 不把教材内容整理成完整题库或答案册；
- 不记录教材全文到学生记忆。
