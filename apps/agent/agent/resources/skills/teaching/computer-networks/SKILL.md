# 计算机网络教材

> 教材：计算机网络（第8版），谢希仁。

## 1. 何时使用

使用：

- 学生要预习、复习或定位计算机网络某一章；
- 学生问分层、协议、算法、设备等课程概念；
- 习题需要确认知识点属于哪一章；
- 考研复习需要把考点映射到教材章节；
- 需要引用教材中的定义、图、表或例题时。

不要使用：

- 实验步骤、traceroute 代码和沙箱操作，走 `traceroute-lab`；
- 教材没有覆盖的内容。

题库检索走 `question-bank` skill 和题库工具；教材正文用于解释、定位和补充。教材习题可以作为参考，但不要编造答案或来源。知识点使用 `textbook/00-toc.md` 的目录编号（如 `5.8.2`、`99`）。

## 2. 资料位置

```text
/skills/teaching/computer-networks/
├── SKILL.md
├── textbook/
│   ├── 00-toc.md          # 书本目录（浏览章节结构）
│   ├── 00-index.md        # 小节 → 文件 → 教材页
│   ├── 01-概述/ ... 09-无线网络和移动网络/
│   └── appendices/
└── figures/
    └── index.md
```

教材正文只读。不要把整章或整本书一次性加载。

## 3. 检索流程

1. **定位**：用 `grep` 在 `textbook/` 里搜小节标题、术语或英文缩写；不确定在哪个文件时，先查 `00-index.md`；
2. **读正文**：用 `read_file` 打开命中的小节文件，读完再判断；
3. **引用**：只取回答需要的一两段，按“章节 + 小节 + 教材第 N 页”作答。

```text
grep -n "拥塞控制" textbook/05-运输层/*.md
```

第一轮没命中就换同义词、英文缩写或相邻小节，不要猜。

`00-toc.md` 只用来浏览章节结构，不能作为引用依据。

## 4. 页码与引用

- 引用页码前先读过该小节正文；页码取自正文开头的出版信息，不取自目录；
- 没读过正文时只提章节名，不给页码；
- 不要引用 PDF 页码，也不要把页码写成文件序号；
- 单页：`见第 4 章 4.2.5，教材第 136 页。`
- 区间：`见第 5 章 5.8，教材第 238–247 页。`

教材没有覆盖时，直接说明这一点，不要编造原文或页码。
