# 题库使用

题库是结构化的题目数据，不写进 `/memory`。本 skill 讲“怎么查、怎么录、怎么展示”。

## 1. 题库边界

- 公共题：教师预置的课程参考题，全体学生可见；
- 私人题库：当前学生自己的题，只有本人可见；
- 公共题不能直接作答，也不加入私人题库；
- 学生要练公共题时，基于题干另出一道私人题，用 `ask_student` 出题；
- 不读取其他学生的题，不发布公共题，不编造题号、年份或来源。

## 2. 知识点

题库使用教材 `00-toc.md` 的目录编号，不使用自由标签。

- 章、节、子节都是合法节点；
- `99` 是跨章节综合节点；
- 每道题必须有一个主知识点，`secondary_knowledge_point_ids` 最多 3 个；
- 主/辅不能重复，辅知识点不能包含主知识点；
- 不确定时用相关小节的 LCA 或父节点，不要编造编号；
- 知识点只用于检索/展示，不做掌握状态、薄弱点、准确率或错题本。

例子：

| 题目 | 主 | 辅 |
|---|---|---|
| TCP 慢开始 cwnd 怎么变 | `5.8.2` | 无 |
| 慢开始和拥塞避免的区别 | `5.8.2` | 无 |
| 拥塞控制一般原理 + 慢开始 | `5.8` | `5.8.1`, `5.8.2` |
| DNS + TCP + IP 综合 | `99` | `6.1.1`, `5.9.1`, `4.2.2` |

## 3. 检索

默认同时搜公共题和私人题库；学生说“我的题”时只搜私人题库，说“课程题/公共题”时只搜公共题。

- 按知识点检索时用教材目录编号，`5` 和 `5.8` 这样的前缀可以筛整个章节；
- 一次最多取 10 条，需要更多再翻页；
- 摘要不含答案，够用来挑题；需要讲解时再取回参考答案，一次最多 3 条；
- 上次作答时间只用于判断“最近练过没有”，不据此推断掌握度、薄弱点或正确率。

检索结果只用于选题或讲解。一次最多向学生展示 3 道题，不贴题库全文，不展示内部编号。

## 4. 出题与录题

- 检查题、引导题：用 `ask_student`，必须标注知识点；学生作答后自动保存题目和答案；
- 学生明确说“把这道题记下来/加入题库”时，才用 `save_question`；只创建私人题；
- 同一道题重复保存会产生多条，不做去重；
- 学生要求发布公共题时，说明当前不支持，建议保存为私人题；
- `save_question` 的单选必须提供 `correct_option`；简答可用 `reference_answer` 给出参考答案。

## 5. 答案与反馈

- 题目答案、`correct_option`、`reference_answer` 不能提前展示；
- `ask_student` 只把学生答案和参考答案交回给你，判分和反馈由你做；
- 单选答对：先确认，再追问“为什么”或换一个条件；
- 单选答错：先问学生怎么排除其他选项，再给提示；
- 简答不结构化判分，按关键点对照参考答案反馈，不要求逐字一致；
- 不把参考答案直接当作完整讲解；先指出学生答对和缺失的关键点。

## 6. 与记忆的关系

- 题库内容、题干全文、选项、答案、解析、作答明细都不写进记忆；
- 记忆只记录概念状态、误解、下一步和“上次同步日期”；
- 需要历史题目或作答时，只检索学生自己的题；
- 不把题库统计写进记忆，也不根据几次作答推断掌握度。

## 7. 调用前检查

- [ ] 知识点使用教材目录编号了吗？
- [ ] 主知识点只有一个，辅知识点不超过 3 个且不重复吗？
- [ ] 只查到了当前学生有权访问的题吗？
- [ ] 取答案只在讲解时用，且没有超过 3 条吗？
- [ ] 没有把答案提前展示给学生吗？
- [ ] 学生明确要求录题时才调用 `save_question` 吗？
- [ ] 没有把题库内容复制进记忆吗？
