# 链路 · 学生端设计说明 v2

> 日期：2026-10-28  
> 范围：`docs/ui`，纯 UI 原型  
> 布局参考：`html2` 原型（侧栏功能入口 + 主区整页切换，未纳入 git）  
> 对应架构稿：`student-ui-frontend-architecture-v1.md`

## 1. 命题

学生端有两个模式：**学习**（对话 + 题库 + 记忆）和**实验**（对话 + 沙盒 + 记忆）。

v2 的布局参考 html2：侧栏承载模式、功能入口和会话；主区在对话、题库、记忆、沙盒之间**整页切换**。没有全局顶栏，也没有右侧上下文面板。聊天仍然是主轴，但题库/记忆/沙盒获得整页空间。

这一版要解决：

1. 侧栏如何同时容纳模式、功能入口和会话，而不显得像设置菜单；
2. 题库从 384px 侧栏搬到整页后，卡片、筛选、详情如何排；
3. 记忆如何利用整页做“目录 + 预览”，而不是列表 → 详情的窄栏；
4. 沙盒如何从状态小卡变成一张可操作的工作区页面；
5. 390px 下没有右侧面板时，如何仍然进入题库/记忆/沙盒并回到对话。

## 2. 视觉方向

仍然沿用 v1 的**纸面、链路、信号**：

- **纸面**：侧栏用 `--paper`，主区用 `--surface`；结构靠 1px 线，不靠阴影。
- **链路**：深青只出现在可操作、可连接、正在发生的地方。
- **信号**：琥珀只给检查点、暂停和需要留意的状态。

参考 html2 的是**布局与信息架构**，不是它的蓝色 Ant Design 视觉：

| html2 | 这一版 |
|---|---|
| 浅蓝侧栏 + 蓝色实心选中态 | 纸色侧栏 + 白色/青色选中态 |
| 蓝色主按钮 + 渐变强调 | 深青主按钮，琥珀只给检查点 |
| 登录卡深海军蓝渐变 | 深墨青整页分栏，叠加分层水印 |
| 大量圆角、轻阴影 | 6–10px 圆角，阴影只给浮层 |

仍然拒绝：奶油底衬线、近黑底荧光绿、全套等宽、每个内容都装进同款卡片、编号与全大写小标签。

## 3. 设计令牌

### 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F2F4F3` | 侧栏 |
| `--surface` | `#FFFFFF` | 主区、卡片、对话框 |
| `--surface-2` | `#F7F9F8` | 用户消息、工具卡、次级块 |
| `--surface-3` | `#EEF2F1` | 分段控件底、hover 底 |
| `--ink` | `#121A1C` | 主文字、登录深色面板 |
| `--ink-muted` | `#5C6E70` | 次级文字、说明 |
| `--line` | `#DCE3E1` | 分隔线、卡片边 |
| `--link` | `#0E6B60` | 主操作、链接、运行中 |
| `--signal` | `#9A5900` | 检查点、暂停 |
| `--danger` | `#B42318` | 销毁、删除、错误 |

### 字阶

| 角色 | 字号 / 行高 / 字重 |
|---|---|
| 登录标题 | 26 / 1.3 / 600 |
| 页面标题（题库/记忆/沙盒） | 24 / 1.3 / 600 |
| 对话正文 | 15 / 1.85 / 400 |
| 卡片正文 | 13.5 / 1.75 / 400 |
| 界面文字 | 12–13 / 1.5 / 500 |
| 辅助信息 | 10–11.5 / 1.5 / 400 |
| 技术数据 | 9.5–12 / 1.7 / 400 mono |

聊天内容宽 840；题库/沙盒内容宽 960；记忆预览在 960 内占剩余宽度。

### 圆角与线

- 控件 6px，卡片/对话框 8–10px。
- 主要结构用 1px `--line`；浮层（Dialog、Sheet、Dropdown、Toast）才有阴影。
- 没有渐变、没有第二套色板、没有装饰性色块。

## 4. 布局

### 桌面 ≥1024

```text
┌──────────────────┬─────────────────────────────────────────────┐
│ 侧栏 284 / 72    │ 主区（无顶栏）                                │
│                  │                                             │
│ 品牌              │ 对话：thread max 840 + 浮动 Composer         │
│ 学习 | 实验       │                                             │
│                  │ 或 题库 / 记忆 / 沙盒：                      │
│ 题库              │     页面标题 24                             │
│ 记忆 6            │     筛选 / 两栏 / 卡片                       │
│ + 新建会话        │                                             │
│ 会话列表          │                                             │
│ 用户              │                                             │
└──────────────────┴─────────────────────────────────────────────┘
```

- 侧栏固定 284，`--paper` 背景 + 右侧 1px 线；可收起到 72 的图标栏，收起后隐藏会话列表，只保留品牌、模式、功能、新建和账户。
- 功能入口不显示数量或状态。
- 主区白色，没有顶栏。会话标题只在侧栏的当前会话里出现；对话页不再有 header。
- 题库/记忆/沙盒页头只有标题（题库带新建），不放说明文字或返回按钮；桌面回对话靠点侧栏已激活的功能入口。
- 对话 thread 840，Composer 840，两者左边缘对齐。
- 题库/沙盒页面 960；记忆 960，内部 300 + 预览。
- 侧栏功能入口是 view 切换：激活项青色浅底，再点一次回到对话。
- 当前会话永远是白色卡片；进入功能页时它仍然保留，提示“在看哪个会话的题库/记忆/沙盒”。

### 平板 768–1023

侧栏隐藏，变成左侧 Sheet；主区加 52px 顶栏（菜单 + 会话标题）。面板整页显示，顶栏右侧出现返回图标。

### 移动 <768

- 顶栏 52px：菜单 44、会话标题、面板时右侧返回图标 44。
- 主区整页切换；Composer 贴底并处理安全区。
- 题库：单列卡片；详情 Dialog；编辑器 footer 吸底。
- 记忆：先目录，选中文件后预览；预览卡头有「文件」返回。
- 沙盒：链接 tile 上下堆叠，返回图标由顶栏提供。

### 登录

- 整页左右分栏，没有外层卡片：左侧深墨青品牌面板，右侧白色表单。
- 左 `0.92fr`：顶部品牌 lockup 为「链路 + 计算机网络教学智能体」（12px、白色 55%、1px 分隔线）；中部为「TCP 三次握手 + 网络分层」图版（握手在上、分层在下），宽度最多 540px，线条白色 18–36%，SYN 用琥珀色；背景是 48px 极淡网格。
- 高度 ≤760px 时隐藏握手图，只保留分层图，避免左栏拥挤；移动端隐藏整个左栏，只保留表单。
- 右 `1.08fr`：标题、说明、学号/密码、登录；不放演示标签、跳过登录或 Mock 说明。
- 移动：隐藏左栏，只保留表单页，顶部品牌；页面固定 `h-dvh`，禁止页面滚动。
- 登录页禁用滚轮和 body 滚动；离开页面时恢复。

## 5. 对话区

### 消息

- 老师：无气泡，正文落在纸面；左侧节点 + 虚线。
- 学生：右对齐 `surface-2` 边框块，最大 86%。
- 连续老师消息合并成一轮，只出现一个节点。
- 日期分隔只在会话顶部出现一次。

### 工具调用

- 一行痕迹：图标 + 等宽工具名 + 摘要 + 状态点 + 耗时 + 展开。
- 终端类默认展开；检索类默认收起；输出最大高度 240，独立滚动。
- 未知工具落回同样的可折叠卡片。

### 作答检查点

- 琥珀顶栏、`ask_student` 等宽标记。
- 题干 14/600；选项整行可点，行高 48。
- 已作答折叠为摘要卡（时间、正确/再想一步、你的选择）。
- 只有学习模式出现。

### Composer

- 840 宽的浮动卡片，和 thread 左边缘对齐；不再用整条顶边框。
- 单行自动增高到 160；`Enter` 发送，`Shift+Enter` 换行，`isComposing` 不发送。
- 忙碌时显示停止；空会话 placeholder 是邀请语。
- 移动端 16px 输入，桌面 14px。

## 6. 整页面板

### 题库

- 页头：标题 24 + 右侧「新建私有题」。
- 筛选：来源分段（全部/公共/我的，带数量）+ 搜索；第二行题型分段 + 知识点下拉 + 数量（桌面）。
- 内容：两列卡片（移动单列）。卡片包含题型/来源、知识点、题干三行截断、作答信息、查看。
- 详情：Dialog，不占第三栏；URL 用 `question` 参数，刷新可还原。
- 答案：默认隐藏；点击「查看答案」后渲染；公共题不可编辑。
- 新建/编辑：Dialog；移动端 footer 吸底，16px 输入。

### 记忆

- 桌面：300 目录 + 预览，两张白卡；各自内部滚动，页面本身不滚。
- 目录：`/memory` 根、目录展开、文件行高 36，选中青色浅底。
- 预览：文件名、路径、更新时间、大小、Markdown。
- 桌面无路径时自动选中 `profile.md`；移动端保持目录列表。
- 移动选中文件后只显示预览，卡头「文件」返回；顶栏返回图标回到聊天。
- 路径在 URL：`?panel=memory&path=/memory/...`。

### 沙盒

- 页头：标题 24。
- 状态卡：状态点 + 运行/暂停/销毁 + 账户级 badge；工作区名、ID 复制、创建/活跃时间。
- 运行：两个入口 tile（VSCode / 终端）；暂停/销毁在底部操作条。
- 暂停：入口 tile 变灰并说明“恢复后才能打开”。
- 销毁：确认后显示启动按钮，说明旧文件不恢复。
- 账户级提示：所有实验会话共享 workspace；删除会话不删文件。

## 7. 移动端

- 侧栏 → 左侧 Sheet；功能入口整页替换对话。
- 52px 顶栏：菜单、当前会话、面板时返回图标。
- 主要操作 44px；密集工具条 32–40px，整行可点。
- 中文输入法 composing 时 Enter 不发送。
- 安全区只处理底部；顶部交给浏览器 chrome。
- 题库详情是 Dialog；记忆是列表 → 文件；都不再叠加第二层 Sheet。

## 8. 动效

- 只有两处非用户触发的动效：生成中节点脉冲、流式文本光标。
- 所有交互反馈用背景/边框/透明度；`prefers-reduced-motion` 下退化为静态。
- 没有整页 fade-up、没有逐卡片入场、没有 hover 缩放。

## 9. 文案

- 动词开头、说清结果：`新建会话`、`打开终端`、`查看答案`、`提交作答`、`销毁沙盒`。
- 空状态是邀请：`从一句话开始` / `先说你想验证什么`。
- 错误说下一步：`已有作答记录，题目暂不可删除`。
- 技术标识（`teach_agent`、`/memory/...`、`ask_student`）保留原文。
- 不把“老师”写成“AI 导师”，不用泛化的“智能助手”。

## 10. 可访问性与边界

- 图标按钮全部有 `aria-label`；表单控件有 label 或 `aria-label`。
- 焦点环用 `:focus-visible`；没有无替代的 `outline: none`。
- 答案在点击前不渲染；Markdown 不启用 raw HTML；外链 `noopener noreferrer`。
- 破坏性操作二次确认；弹层 `overscroll-behavior: contain`。
- 没有做完整 axe 矩阵、键盘走查和读屏测试。

## 11. 取舍与待确认

| 事项 | 当前选择 | 备注 |
|---|---|---|
| 工作台入口 | 登录后默认进学习工作台 | 模式选择页移除；学习/实验在侧栏切换 |
| 面板形态 | 整页替换对话 | 参考 html2；不再有右侧面板 |
| 移动端深度 | 完整操作 | 发消息、作答、题库、记忆、沙盒启停 |
| 深色模式 | 不做 | 令牌可后续替换 |
| 题库筛选 URL | 不做 | 面板/题目/记忆路径已进 URL |
| 记忆编辑 | 不做 | 对应 P0 的只读边界 |
| 沙盒生命周期 | 只显示状态与时间 | 不编造事件流 |

## 12. 与生产架构的对应

| 原型 | 生产建议 |
|---|---|
| React Router | TanStack Router；search 用 Zod 校验 |
| 内存 store | TanStack Query + assistant-ui runtime |
| 整页面板 | 路由级 view 或条件渲染；面板状态进 search |
| `CheckpointCard` | `useLangChainInterruptState` + Zod 解析 |
| 工具卡 | `ToolCallMessagePartProps` registry，未知工具 fallback |
| 沙盒入口 | 打开前显式 ensure；轮询只在实验模式 |

实现时请保留本轮确定的：284 / 72 可收起侧栏、840 对话宽度、960 面板宽度、28px 链路槽、侧栏功能入口 + 整页切换、移动端 52px 顶栏与返回图标、琥珀检查点，以及“技术数据才用等宽”的规则。
